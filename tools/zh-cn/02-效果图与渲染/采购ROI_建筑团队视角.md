## 四、ROI 汇总

| 方案 | 年成本 | 年节省（vs 全外包） | 回本周期 | 适合团队 |
|---|---:|---:|---|---|
| 全外包 | 45-72 万 | — | — | 交付级渲染要求高、内部无 AI 能力 |
| EVAI + 建筑学长 | ~0.7-1.2 万 | 44-71 万 | < 1 周 | 建筑方案团队、学生/年轻建筑师多的工作室 |
| GPT/Gemini + Magnific | ~0.5-1.0 万 | 44-71 万 | < 1 周 | 需要分析图、概念图、图像增强、Relight、素材版本管理和传播资产的团队 |
| Abacus + Kling | ~0.4-1.9 万 | 43-71 万 | < 2 周 | 想低成本试多模型，或有视频汇报/传播需求的团队 |

核心结论：AI 工具采购的直接成本通常不是瓶颈，真正要控制的是“重复试错消耗”和“谁负责最终画面 QA”。对建筑工作室来说，最稳妥不是买单一万能工具，而是把采购拆成三个岗位：建筑垂直出图、语义/分析图、创意资产工作流。

采购时可按 5 个岗位拆分，而不是问“哪个生图工具最好”：

| 岗位 | 采购目标 | 候选工具 |
|---|---|---|
| 语义表达 | 分析图、解释型图像、文字标注、多轮改图 | GPT-image / Gemini |
| 建筑渲染 | 白模、草图、SU 截图转建筑/室内/景观效果图 | EVAI / 建筑学长 |
| 可控工作流 | 结构控制、批量一致性、本地部署 | ComfyUI / Stable Diffusion / Flux |
| 创意后期 | 放大、增强、Relight、局部修补、封面精修 | Magnific / Topaz / Krea |
| 动态传播 | 图生视频、运镜、续写、路演短片 | Kling / Runway / Seedance |

## 五、不能只看价格——质量和适用边界

### 用 AI 能覆盖的场景

| 图类 | AI 替代程度 | 推荐工具 | 说明 |
|---|---|---|---|
| 概念方案比选 | ✅ 100% | Gemini / GPT-image / 建筑学长 | 快速出多套方向，适合早期讨论 |
| 人视效果图（方案阶段） | ✅ 80-90% | EVAI / 建筑学长 | 可到汇报级，细节硬伤需人工修 |
| 分析图/功能分区图 | ✅ 70-85% | GPT-image / Gemini | AI 生成底图 + 手动标注更高效 |
| 创意后期/资产增强 | ✅ 80-90% | Magnific | 图像增强、Relight、局部修补、版本管理最确定；生成、视频、音频、3D、Stock/Flows 属于扩展价值，需项目实测 |
| 方案视频化汇报 | ⚠️ 50-80% | Kling | 适合氛围短片，不适合替代真实漫游动画 |
| 鸟瞰效果图 | ⚠️ 50-70% | EVAI + 人工后期 | 大面积场景 AI 结构控制仍不稳定 |
| 室内工装 | ⚠️ 60-80% | EVAI / 建筑学长 / GPT-image | 家装可用，复杂工装细节容易翻车 |

### 仍然需要外包/人工的场景

| 场景 | 原因 |
|---|---|
| 施工图交付级效果图 | AI 细节不达施工精度，甲方的“交付标准”是硬门槛 |
| 需要精确结构约束的项目 | 历史保护/改造类项目，每一根柱子都不能变 |
| 甲方有“手绘风/特定风格”硬性要求 | AI 的风格一致性在多轮修改中可能漂移 |
| 超大鸟瞰/规划总图 | 拼接+修图工作量大，AI 一次生成整图成功率低 |
| 带品牌 logo、精确文字、精确节点的图 | Magnific/GPT-image 等都会改写局部事实细节 |

## 六、推荐的混合采购策略

按项目阶段分工具：

```text
前期概念（生成 6-8 套风格方案）
  → GPT-image / Gemini / 建筑学长
  ↓
中期方案（2-3 套方向深化）
  → EVAI / 建筑学长（结构控制 + 批量输出）
  ↓
汇报前（精选 15-20 张精修）
  → Magnific + Photoshop（图像增强、Relight、局部修补、版本管理）
  ↓
传播与路演（可选视频化）
  → Kling 铂金先试水；只有高频视频需求再上黑金
  ↓
交付级（5-8 张核心效果图）
  → 外包效果图公司（1,200-1,500 元/张）——最后一道防线
```

建议的第一轮采购组合：

1. **必买/优先试用**：EVAI + 建筑学长，用来覆盖建筑垂直出图。
2. **已有 ChatGPT 工作流则买**：GPT-image，用于分析图、文本理解和多轮改图。
3. **按项目买**：Magnific，用于图像增强、Relight、Spaces 版本管理、封面/投标图精修；跨媒体功能先实测再扩大采购理由。
4. **暂不重仓**：Kling 黑金，除非已经有持续视频交付；先用铂金或短期会员验证。
5. **实验位**：Abacus AI，适合用较低月费试多个海外模型入口，但不应承诺稳定建筑交付。

**年成本估算：约 1-2 万 AI 工具 + ~10 张交付级外包 × 1,400 元 = 2.4-3.4 万**
**年节省（vs 全外包 45-72 万）：约 42-69 万**

## 七、隐藏成本提醒

1. **学习成本**：方案主创学会 EVAI/建筑学长/GPT-image/Magnific 的组合工作流需要 2-4 周。
2. **审美和判断力成本**：AI 出图快但“垃圾进垃圾出”，提示词和图像筛选仍依赖人。
3. **风格漂移**：同一个项目多轮生成可能出现风格不一致，需要有人专门做风格 QA。
4. **账号与并发**：企业采购前必须确认是否支持多人同时登录、成员管理、额度共享和发票。
5. **credits 消耗不可线性估计**：Magnific、Abacus、Kling 都可能因高质量模型、视频、放大、Relight、生成、重试消耗远超预期。
6. **数据与版权**：涉及未公开项目、甲方资料、品牌资产时，不建议上传到未知共享号或第三方代充平台。
7. **桌面端 ≠ 零成本**：RTX 4090 约 1.3-1.5 万/张，3 年折旧，每年 ~5,000 元/台；如为 EVAI 专配新卡需计入。
