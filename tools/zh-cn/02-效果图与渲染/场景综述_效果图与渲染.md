# 场景综述：效果图与渲染

> 文档日期：2026-06-12
> 目的：从设计师、产品、技术三层视角整合效果图生成场景的完整认知

## 一、设计师视角：该用什么出图？

### 生图工具的细分品类

“生图工具”不能只按文生图/图生图划分。建筑场景更应该按它在工作流中的位置来分：谁负责语义表达，谁负责结构约束，谁负责后期增强，谁负责动态传播。

| 品类 | 核心能力 | 代表工具 | 建筑场景价值 | 主要风险 |
|---|---|---|---|---|
| **语义表达型** | 对话式生成、多轮改图、文字标注、分析图/技术图解 | GPT-image 2、Gemini / Nano Banana、豆包 | 概念探索、分析图、带说明文字的汇报图 | 结构硬约束弱，不能保证白模比例和构造细节 |
| **审美创意型** | 高质感风格、氛围图、艺术化视觉探索 | Midjourney、Freepik / Mystic、Leonardo | 封面图、竞赛氛围、前期灵感板 | 好看但难精确修改，方案深化成本高 |
| **建筑垂直渲染型** | 草图/白模/SU 截图转建筑、室内、景观效果图 | EVAI、建筑学长、酷家乐 AI、模袋云 AI | 方案阶段快速出汇报级效果图 | 平台能力差异大，复杂细部仍需人工修图 |
| **可控工作流型** | ControlNet、Depth、Canny、LoRA、IPAdapter、批量工作流 | Stable Diffusion、ComfyUI、Flux 本地工作流 | 结构控制、风格一致、私有化部署、批量出图 | 学习和维护成本高，对 GPU/节点理解有门槛 |
| **创意后期型** | 放大、补细节、Relight、局部修补、版本管理 | Magnific、Topaz、Krea | 展板级增强、营销封面、投标图精修 | 容易改写材料、分缝、文字、logo 等事实细节 |
| **动态传播型** | 图生视频、运镜、续写、首尾帧、音画同步 | Kling、Runway、Pika、Seedance、Sora | 方案汇报短片、竞赛动画、社媒传播素材 | 不适合替代真实漫游动画和施工级模拟 |
| **软件内嵌型** | 在建模/渲染/BIM/家装软件中直接生成或增强 | Veras、D5 AI、Enscape AI、酷家乐、三维家 | 不打断建模流程，适合日常预览和快速沟通 | 常受宿主软件生态和订阅绑定限制 |

### 按出图阶段选工具

| 阶段 | 推荐工具 | 理由 |
|---|---|---|
| **概念探索**（快速试风格） | GPT-image 2 / Nano Banana / Midjourney | 语义理解和审美探索快，适合先形成方向而不是直接交付 |
| **方案深化**（需要结构控制） | EVAI 桌面端 / 建筑学长 / ComfyUI | 需要白模、线稿、深度图、参考图等约束来控制比例和空间关系 |
| **创意后期/资产增强**（展板、封面、视频化） | Magnific / Topaz / Krea | 负责把已有图像提升到展板、封面、投标、传播可用的质量 |
| **动态汇报**（视频和路演） | Kling / Runway / Seedance | 负责把静态效果图转成运镜、续写、音画同步的动态资产 |
| **团队协作**（多人共用） | EVAI 桌面端 / ArchLink M2 | 前者桌面端免订阅+本地 GPU，后者项目式保存+预设共享 |

### 按预算选工具

| 预算 | 推荐 | 成本 |
|---|---|---|
| **零预算** | Stable Diffusion WebUI（本地）+ 开源模型 | 电费 ~$0.001/张 |
| **低预算**（<¥50/月）| 建筑学长免费版 / ArchLink M2 入门 | 0-¥10/月 |
| **中预算**（¥50-200/月）| EVAI 云端 + 建筑学长会员 | ~¥100-200/月 |
| **高预算**（>¥200/月）| MJ + Magnific + EVAI 全栈 | ~¥300-500/月 |

### 建筑师常见误区
1. **"MJ 最好看所以应该选 MJ"** — MJ 的审美确实好，但出图后的结构修改无法做。方案深化阶段可控性比审美重要。
2. **"有了 AI 就不用学渲染了"** — AI 出图快但风格漂移、细节硬伤需要手动修。Photoshop 修图能力仍是 AI 效果图流的必备技能。

## 二、产品视角：竞品格局与机会

### 三层产品矩阵

```
第一层：通用引擎层（不面对建筑师）
  Midjourney | Stable Diffusion | DALL-E 3/GPT-image 2 | Nano Banana
  ↓ 封装/调优/加控制
第二层：建筑垂直平台
  EVAI | 建筑学长 | ArchLink M2 | 模袋云AI | 云图AI | 豆绘AI
  ↓ 嵌入工作流
第三层：传统渲染工具链（不可替代的最后防线）
  V-Ray | Enscape | Lumion | D5 Render
```

### ArchLink M2 的竞争对比

| 维度 | ArchLink M2 vs EVAI | ArchLink M2 vs 建筑学长 |
|---|---|---|
| **出图质量** | 未验证 | 未验证 |
| **速度** | 未验证 | 更慢（云端） |
| **资产管理** | 支持（项目保存+预设共享） | 不支持 |
| **生态依赖** | EVAI 有桌面端优势 | 建筑学长有 100+ 高校+SU/Rhino 插件 |
| **价格** | 入门 ¥9.9（主力 ¥99） | 建筑学长年付 ¥21.6/月 |

### 竞品动态与市场空白

- **竞争动态**：建筑学长如果在现有功能上加项目管理和预设共享，将补齐当前市场上"资产管理"维度的空白
- **市场空白**：目前没有产品做到"出图+案例匹配+规范审查+PPT 输出"的一体化。全链路整合可能产生 1+1+1+1>4 的效应

## 三、技术视角：三条路线的融合趋势

### 当前三条路线

| 路线 | 代表 | 核心架构 | 最适合 |
|---|---|---|---|
| **扩散模型** | SD3.5/Flux | U-Net → MMDiT/DiT，噪声→去噪 | 本地部署、可定制、结构控制 |
| **自回归多模态** | Nano Banana (Gemini) | MoE Transformer，图+文统一 token | 文字渲染、语义理解、多参考融合 |
| **混合架构** | GPT-image 2 | 自回归语义规划 + 扩散解码 | 语言能力强 + 画质好 |

### 技术趋势

1. **三条路线正在融合**：SD3.5 引入 Transformer（MMDiT），GPT-image 用扩散 head，Nano Banana 的自回归路线把图文统一到同一 token 空间
2. **ControlNet 是建筑师的刚需**——无论哪种路线，结构控制能力（Canny/Depth/MLSD/Semantic）是建筑师选择工具的决定性因素
3. **ComfyUI 生态的潜力**：EVAI 桌面端本质是 ComfyUI 工作流封装——如果能将建筑师的"最佳实践工作流"沉淀为可复用的节点组合，会形成强大的迁移壁垒
4. **论文线索正在转化为评测指标**：ControlNet / T2I-Adapter / IP-Adapter 对应结构与参考图控制，DiffBIR / 超分方向对应后期保真，Stable Video Diffusion / ConsistI2V / CameraCtrl 对应图生视频稳定性。论文不直接证明产品能力，但能帮助评测从“好不好看”拆成可验证指标。
5. **Agent 化会改变插件工具的判断口径**：插件型工具如果只能截图上传，仍是 Web 生图入口；如果能读取模型、相机、材质、图层并执行多步修改，就应按设计软件 Agent 的方式评测。

## 阶段复盘

当前效果图研究已经完成场景边界、竞争地图、套壳技术框架、插件深度核验和论文线索整理。下一步不宜继续扩大工具名单，而应优先补齐 Veras、LookX、D5 Render AI 等 P0 单工具评测，并用 S1 白模、S2 手绘、S5 后期增强、S6 图生视频四类最小样本验证结构保真、后期保真和视频稳定性。
