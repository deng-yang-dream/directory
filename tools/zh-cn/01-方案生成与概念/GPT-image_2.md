# GPT-image 2 (ChatGPT Images 2.0)

> 文档日期：2026-06-12 | 编辑：待填
> 价格：ChatGPT Plus $20/月（含 Thinking Mode），API $0.006-0.35/张 | 上手难度：零门槛
> (已删除)：★★★★

## 一句话评价
ChatGPT 体系下的对话式视觉表达入口，强项不只是文生图，而是语义理解、分析图/技术图解、文字标注和多轮自然语言改图。

## 推荐与否
推荐 — 对需要快速概念探索、技术图解/分析图生成、带文字视觉表达和多轮改图的建筑师来说，是目前上手门槛最低的对话式视觉工具。

## 核心优缺点

优点：
1. **语义理解最强**：直接继承 GPT-4o 的语言推理能力，复杂空间关系的文字描述能被准确理解，无需学习 prompt engineering 技巧
2. **文字渲染 99% 准确率**：中英文标注、展板标题、技术图解说明文字几乎不出错，适合汇报用分析图
3. **对话式多轮编辑**：改局部不必重画整张，用自然语言说"去掉那棵树"、"把立面改成砖墙"即可
4. **Thinking Mode 语义规划**：先生成文字方案（布局/色彩/构图），再扩散渲染，复杂输出更可控
5. **多图一致性**：单次最多生成 8 张风格一致的效果图，适合多角度方案展示

缺点/不足：
1. **不支持结构约束**：无 ControlNet 式几何控制，不能基于 SU/Rhino 线稿精确出图——场景宽度不如 SD/ComfyUI
2. 完全闭源，无法本地部署，不可微调，API 无细粒度参数控制
3. API 计费按 token 不透明——单张成本难以预估，批量出图时费用容易失控

## 适合人群
- 推荐给：方案主创（概念探索 + 分析图生成）、需要精准文字标注的汇报用图制作者、不想学 ComfyUI 的建筑师
- 不推荐给：需要精确结构还原的效果图公司、需要批量标准化出图的设计院、对成本敏感的独立建筑师

## 比同类好在哪
vs Nano Banana：GPT-image 胜在对话式编辑的深度（多轮改图体验最流畅）、文字渲染准确性、Thinking Mode 的语义规划到像素渲染全链路控制；Nano Banana 胜在多参考图融合上限（14 张）、Search Grounding 核实地标真实性、百万 token 上下文。vs Midjourney：MJ 胜在审美质感，GPT-image 胜在语义理解和文字渲染。

## 技术栈推测
底层基于 **GPT-4o 的混合架构**：文本指令 → GPT-4o 自回归语义规划（生成粗粒度语义 token）→ 扩散解码器渲染为像素图像。C2PA 元数据证实了 GPT-4o 作为底层引擎。这个"LLM 负责想清楚画什么，扩散负责画好看"的路线，让语义理解远超纯扩散模型，文字渲染的准确率也来自自回归侧对离散符号的原生支持。
